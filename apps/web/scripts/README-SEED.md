# الحساب التجريبي وبيانات العرض

هذه الأداة تجهّز وكالة مخصّصة للعرض باسم **حساب تجريبي**، وتملؤها ببيانات مترابطة
توضح شكل النظام بعد الاستخدام. لا تنشئ مستخدماً ولا تغيّر بريده أو كلمة مروره؛ يجب
إنشاء حساب التجربة بالطريقة المعتادة أولاً، ثم تُضاف البيانات إلى وكالته فقط.

## قواعد الأمان

- لا تُشغّل على الإنتاج مطلقاً، بل على قاعدة معاينة مستقلة فقط.
- لا تقرأ الأداة `DATABASE_URL` العام أو ملفات الإعداد تلقائياً.
- يلزم تحديد رابط قاعدة المعاينة والبريد ومعرّف الوكالة وتأكيد مطابق لها جميعاً.
- تتحقق الأداة من ارتباط البريد بالوكالة ومن أن كليهما نشط قبل أي إضافة.
- لا تحفظ كلمة مرور افتراضية داخل المستودع.
- إذا وجدت بيانات عرض من الإصدار القديم، تتوقف دون حذف أو تكرار.

## ما الذي تضيفه؟

| المجال | بيانات العرض |
|---|---|
| العملاء والموردون | عميل فردي، شركة مسجلة ضريبياً، شركة طيران، وفندق |
| عروض الأسعار | عرض مُرسل، وعرض تحوّل إلى حجز |
| الحجوزات | طيران بصفتنا وكيلاً، وباقة وعمرة بصفتنا أصيلاً، وحجز لم يُفوتر بعد |
| الفواتير والتحصيل | فاتورة مدفوعة، فاتورة جزئية، خطة قسطين، وسندات قبض |
| الاسترداد | استرداد جزئي، دفعة سالبة، مذكرة دائنة، وحركة سحب بنكية |
| المحاسبة | قيود متوازنة، إيراد مؤجل، ذمم عملاء وموردين، وضريبة قيمة مضافة |
| الخزينة | حساب بنكي، صندوق، إيداعات، سحوبات، ودفعة مورد بعملة أجنبية |

## التشغيل المصرّح به

يتم التشغيل فقط بعد موافقة صريحة على قاعدة المعاينة المحددة. من جذر المشروع:

```powershell
$env:DEMO_DATABASE_URL = 'postgresql://رابط-قاعدة-المعاينة'
$env:DEMO_SEED_EMAIL = 'بريد-الحساب-التجريبي'
$env:DEMO_SEED_AGENCY_ID = 'معرف-وكالة-التجربة'
$env:DEMO_SEED_TARGET = 'isolated-preview'
$env:DEMO_SEED_CONFIRM = 'SEED:معرف-وكالة-التجربة:بريد-الحساب-التجريبي'
pnpm --filter @masarat/web exec tsx scripts/seed-demo.ts
```

إعادة التشغيل على المجموعة نفسها لا تنشئ نسخاً جديدة؛ المعرفات ثابتة والإضافات
تتجاهل السجلات الموجودة. ومع ذلك لا تُستخدم الأداة كوسيلة لتنظيف البيانات أو حذفها.
